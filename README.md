# Таймер на весь экран

Простой статический сайт без сборки и зависимостей: `index.html`, `style.css`, `app.js`.
Весь экран заполнен элементами, и каждый из них — доля оставшегося времени. По ходу отсчёта
элементы уходят с экрана в выбранном порядке и с выбранным эффектом, так что сколько осталось,
видно издалека.

## Запуск

- Открыть `index.html` в браузере, или
- выложить папку на любой статический хостинг (Vercel с пресетом **Other** без команды сборки,
  GitHub Pages, Netlify).

Ссылка сразу с нужным временем: допишите к адресу `#25m`, `#1h30m`, `#90s` или `#25`
(число без букв — минуты). До определённого времени: `#18-00`.
Работает и `?t=25`, `?t=5:00`, `?until=18:00`; с `&autostart=1` отсчёт начнётся сам.

## Настройки (кнопка с ползунками или клавиша `S`)

- **Время**: два режима.
  - *Длительность*: часы / минуты / секунды и быстрые пресеты.
  - *До времени*: укажите, во сколько закончить (например, 18:00), и таймер сам посчитает остаток.
    Если это время сегодня уже прошло, отсчёт пойдёт до завтра. Пауза не сдвигает окончание.
- **Элементы на экране**: по размеру (px), точным количеством или «1 элемент = отрезок времени»
  (например, 1 элемент = 1 минута), отступ, скругление (до кругов).
- **Порядок ухода**: построчно, снизу вверх, по столбцам, змейкой, по диагонали, по часовой стрелке,
  спиралью внутрь/наружу, кругами из центра/к центру, шторками, случайно; обратный порядок;
  режим «заполнять» вместо «опустошать».
- **Как уходит элемент**: затухание, затемнение до чёрного, сжатие, вращение, переворот,
  падение вниз, улёт вверх, разлёт в стороны; плавно (с настраиваемой шириной фронта)
  или шагами с анимацией.
- **Цвета**: готовые темы, фон, окраска по оставшемуся времени (пороги «мало» и «почти всё»),
  градиент по порядку или один цвет, цвет следа ушедших.
- **Затемнение**: яркость следа ушедших элементов, общая яркость, затемнение экрана к концу,
  пульсация и тиканье в финальные секунды.
- **Цифры**: размер, положение, формат (ММ:СС, Ч:ММ:СС, секунды, проценты, оставшиеся элементы),
  цвет, прозрачность, время окончания.
- **Финал**: звук, мигание экрана, счёт времени после нуля.
- **Интерфейс**: размер кнопок, автоскрытие кнопок во время отсчёта.

Кнопка **Демо** прокручивает весь отсчёт за 5 секунд, чтобы сразу увидеть, как выглядят настройки.
Настройки и состояние таймера сохраняются в браузере (переживают перезагрузку страницы).

## Клавиши

| Клавиша | Действие |
| --- | --- |
| Пробел | старт / пауза |
| R | сброс |
| ↑ / ↓ | плюс / минус минута |
| F или двойной клик | полный экран |
| S | настройки |
| D | демо |
| Esc | закрыть панель / выключить сигнал |
